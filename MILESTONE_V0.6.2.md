# Msingi Accounting v0.6.2 — Compact Dashboard & Financial Reporting

## Dashboard improvements
- Consolidated the dashboard KPI tiles into one Financial Overview card.
- Preserved all-time income, expenses and net position.
- Preserved cash and bank, receivables (owed to you) and payables (you owe).
- Preserved current-month income, gross profit (when cost of goods sold is available) or monthly expenses, and net profit/loss.
- Added a compact three-column metric layout with smaller icons and clear colour cues.
- No accounting calculations, journal posting, database schema or stored transaction data were changed for this layout update.

## Release
- Application version: 0.6.2
- Target: Intel macOS (x86_64)
- Installer: Msingi-Accounting-v0.6.2-Intel-Mac.dmg
